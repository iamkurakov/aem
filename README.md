# Маркетинговое исследование АЕМ Холдинг

Открыть сайт — [iamkurakov.github.io/aem](https://iamkurakov.github.io/aem/).

Главная страница содержит пять разделов исследования. Полные главы открываются под краткими выводами. Исходный отчёт, база отзывов, сравнительная матрица, реестр инициатив и список источников находятся в `data/`.

Сайт статический. Для GitHub Pages используется корень ветки `main`.

Дата среза — 26 ноября 2026 года. Логотип, оформление и фотография дилерского центра основаны на материалах [официального сайта АЕМ Холдинг](https://aemholding.ru/) и [страницы контактов](https://aemholding.ru/contact). Исследование подготовлено по открытым источникам.
